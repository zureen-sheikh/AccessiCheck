Questions
Frequently asked questions.




What is web accessibility?
It means building websites that people with disabilities can use too, for example blind users who rely on screen readers, or people who cannot use a mouse.


Which problems does AccessiCheck find today?
Six checks: images without alt text, form fields without labels, links with no text, low colour contrast, wrong or missing ARIA roles, and a live URL scan for real websites.


Can it scan any website?
It can scan public websites. For safety, addresses on your own computer or private network are blocked. Colour contrast is checked for inline styles only.


Does it change my code automatically?
Only when you press Apply all fixes. You can compare Before and After for every issue, and copy the fixed code.


Is my code stored?
No. Only the scan date, the score, the number of issues and the source (for example the website name) are saved in the database. Your HTML is not saved.


What is it built with?
Java 17 and Spring Boot for the server, Jsoup to read the HTML, an H2 database for scan history, and plain HTML, CSS and JavaScript for the pages.
