What We Check

Six checks, all live.

🖼️ Missing alt text

An image without a description. A blind user hears nothing useful.

<img src="a.jpg">

📝 Unlabeled field

An input with no label. Users do not know what to type.

<input name="email">

🔗 Empty link

A link with no text. The screen reader only says “link”.

<a href="x.html"></a>

🎨 Colour contrast

Text that is hard to read on its background. We suggest a better colour.

<p style="color:#aaa">

⌘ ARIA roles

Wrong roles, controls the keyboard cannot reach, or focusable items hidden from screen readers.

<div role="buttn">

🌐 Live URL scan

Type a website address and scan the real page.

Features

Guide

How to use AccessiCheck in four steps.

  1. Open New Scan, then paste your HTML code or type a website address.
  2. Press Analyze code. The tool reads every tag.
  3. Read the Result. Fix the Critical issues first.
  4. Press Apply all fixes and watch the score go up. Track it in History.
